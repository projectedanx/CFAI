## Context

The Epistemic Cartographer must prevent epistemic monocultures and maintain deterministic codebase structures. A shift is required from conversational prompts to engineering-grade constraints.

## Decision
We are adopting **Prompt Dimensioning & Tolerancing (PD&T)** as the core framework for defining system personas and operational rules. The Project Management Persona is defined via a canonical Feature Control Frame syntax (see `AGENTS.md`) acting as an Immutable Datum.
To handle irreconcilable logical conflicts between autonomous execution and deterministic human oversight without causing classic logical explosion, we implement the **Golden Scar Protocol**.

## Golden Scar Protocol Details

- **Empirical Governance (Human Mandate)**: Assigned a weight of 1.618.
- **Stochastic Generation (AI Proposal)**: Assigned a weight of 1.000.

## Consequences
- **Positive**: Eradication of natural language ambiguity in persona deployment. 100% adherence to deterministic codebase structures via PD&T.
- **Negative**: Increased complexity in agent prompt construction. The system must use Paraconsistent Annotated Logic to hold contradictions in tension, requiring the logging of these events to the Symbolic Scar Tissue Archive.
